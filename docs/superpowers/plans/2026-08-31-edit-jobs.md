# Background Image Edit Jobs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run Playground image edits as detached background jobs so edited images reliably appear in the right-side gallery even when generation exceeds the browser or proxy request lifetime.

**Architecture:** Add a multipart edit-job endpoint alongside the existing JSON generation-job endpoint. Reuse one edit parser for the synchronous compatibility endpoint and the job endpoint, then run `executor.edit` without the client request signal and publish localized files through the existing `JobManager`. The web app submits edit `FormData` to the new endpoint and reuses its existing job persistence, polling, rendering, and cancellation behavior.

**Tech Stack:** TypeScript, Fastify 5, `@fastify/multipart`, React 18, Vitest, SQLite, native `fetch`/`FormData`.

---

- [ ] **Step 3: Extract the parser**

Add `ParsedEditRequest` and `parseEditMultipart(req)` to `server/src/server/edits.ts`. It must reject non-multipart requests, consume file parts into `IncomingImage`, require at least one `image`, validate `model`, `prompt`, and common fields, and return `{ model, editReq }`.

```ts
export interface ParsedEditRequest {
  model: string;
  editReq: UnifiedEditRequest;
}

export async function parseEditMultipart(req: FastifyRequest): Promise<ParsedEditRequest> {
  if (!req.isMultipart()) throw new ValidationError("request must be multipart/form-data");
  const fields: Record<string, unknown> = {};
  const images: IncomingImage[] = [];
  let mask: IncomingImage | undefined;
  for await (const part of req.parts()) {
    if (part.type === "file") {
      const image = { filename: part.filename || "image.png", data: await part.toBuffer(), mimeType: part.mimetype || "image/png" };
      if (part.fieldname === "image") images.push(image);
      else if (part.fieldname === "mask") mask = image;
    } else fields[part.fieldname] = part.value;
  }
  if (images.length === 0) throw new ValidationError("'image' file is required");
  const model = requireString(fields, "model");
  const prompt = requireString(fields, "prompt");
  const common = validateCommonFields(fields);
  return { model, editReq: { prompt, n: common.n, size: common.size, responseFormat: common.responseFormat, images, mask, passthrough: common.passthrough } };
}
```

Replace the inline parser in `registerEdits` with `const { model, editReq } = await parseEditMultipart(req);`.

```ts
export async function createEditJob(form: FormData): Promise<{ jobId: string }> {
  const res = await fetch("/v1/images/edit-jobs", {
    method: "POST",
    headers: { authorization: `Bearer ${getToken()}` },
    body: form,
  });
  const parsed = (await res.json().catch(() => ({}))) as { jobId?: string; error?: { message?: string } };
  if (!res.ok || !parsed.jobId) throw new ApiError(res.status, parsed);
  return { jobId: parsed.jobId };
}
```
